# Student Assignment Tracker

A full-stack web application that helps students manage and track their assignments efficiently.

## Features

- View assignment information.
- Add new assignments.
- Store assignment data in a MySQL database.
- Retrieve assignment data through a FastAPI backend.
- Use a simple frontend built with HTML, CSS, and JavaScript.

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, FastAPI
- **Database:** MySQL
- **Tools:** Visual Studio Code, Git, GitHub
